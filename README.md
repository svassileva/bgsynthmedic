# BGSynthMedic: Synthetic Parallel English-Bulgarian Discharge Summary Corpus with Automatic Annotations

Parallel corpus of English-Bulgarian synthetic discharge summaries automatically translated and validated from SynthMedic (https://huggingface.co/datasets/grazh/synth-medic).

Citation:
```
Boytcheva, S., Vassileva, S., & Boytchev, P. (2026). BGSynthMedic: Synthetic parallel English-Bulgarian discharge summary corpus
with automatic annotations. In Proceedings of the International Conference on Computational Linguistics in Bulgaria (CLIB 2026).
```
